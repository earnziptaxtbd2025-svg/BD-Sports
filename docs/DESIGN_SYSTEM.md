# Design System (Step 0.5)

Source of truth: the approved design PDF (dark "stadium night" neon style). Built in
four parts so each part can be tested on a phone before the next begins.

| Part | Content | Status |
|---|---|---|
| 1 | Colours, spacing, radius, glow and gradients, text styles, dark neon theme | Written |
| 2 | Glass card, neon buttons (green, blue, purple, red, outline), tab bar, badges, input field (`lib/core/widgets/`) | Written |
| 3 | LIVE badge, score header, stat bars, stepper, bottom navigation with raised centre button | Written |
| 4 | Bottom navigation connected, image slots, logo, Design Gallery screen, tests | Written |

## Rules

- Screens use `AppColors`, `AppSpacing`, `AppRadius`, `AppEffects` and `AppTextStyles`
  from `lib/core/theme/`. No raw colour values or loose font sizes in screens.
- Left team is blue, right team is red. Gold is for trophy, captain, money and target.
  Neon green is for primary actions, active tabs and LIVE or approved states.
- Minimum tap height is 48.
- Dark neon is the default theme. The light theme is kept. A user setting comes in
  Step 1B.13.

## Image assets the owner provides (not generated by code)

App logo (shield), stadium background, trophy image, onboarding player images.
Team logos and tournament posters are uploaded by users.

## Part 2 widgets (`lib/core/widgets/`)

| Widget | Use |
|---|---|
| `GlassCard` | Base card. Optional glow colour and tap. |
| `NeonButton` | Main button. Styles: green, blue, purple, red, outline. Has loading and disabled state, optional icon and second line. |
| `NeonTabBar` | Row of pill tabs. Scrolls sideways if it does not fit. |
| `AppBadge` | Small status or role label. Tones: success, warning, danger, info, blue, purple, orange, neutral. |
| `NeonTextField` | Labelled input with validator support. Pill for one line, rounded box for many lines. |

Tests: `test/design_widgets_test.dart`.

## Part 3 widgets (`lib/core/widgets/`)

| Widget | Use |
|---|---|
| `LiveBadge` | Red LIVE badge with blinking dot. Stops blinking when the phone reduces animations. |
| `TeamCrest` | Round badge with team letters until a team uploads a logo. |
| `ScoreHeader` | Two teams plus score. Football ("1 - 0") and cricket ("180/5"). Glows when live. |
| `StatBar` | One statistic of both teams with a split bar (possession, shots, corners). |
| `NeonStepper` | Step indicator for multi-step forms. |
| `NeonBottomNav` | Bottom navigation with an optional raised round centre button. |

Tests: `test/design_match_widgets_test.dart`.

`NeonBottomNav` is now the bottom navigation of the app (`MainShell`). The existing
navigation tests were changed to look for it instead of the plain `NavigationBar`.

## Part 4

- `NeonBottomNav` is connected in `lib/features/shell/presentation/main_shell.dart`.
  The middle item (Create) is the raised round button.
- Image slots: `assets/images/` (see its README). Paths are in `lib/core/theme/app_assets.dart`.
  `StadiumBackground` and `AppLogo` draw a fallback when a file is missing.
- Design Gallery: developer screen with every widget. Open it from Profile, under the
  developer tools (only when the app is built with DEV_TOOLS). Path `/dev/design`.
- Bangla font: the app asks for "Noto Sans Bengali" and Android phones normally have
  it. No font file is bundled yet. If Bangla letters look wrong on a phone, a font
  file is added to `assets/fonts/` and declared in `pubspec.yaml`.

Tests: `test/design_gallery_test.dart`.
