# Image slots

Put the app images here with exactly these names. Until a file is added, the app shows
a drawn fallback (gradient or icon), so nothing breaks.

| File | Used for | Suggested size |
|---|---|---|
| `logo.png` | App logo (shield with ball and crown), transparent background | 512 x 512 |
| `stadium_bg.jpg` | Dark stadium background behind screens | 1080 x 1920 |
| `trophy.png` | Gold trophy image, transparent background | 512 x 512 |

Team logos and tournament posters are uploaded by users, not stored here.
